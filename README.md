# 🚀 NOMO Car Hire - The Future of Mobility

NOMO is a cutting-edge mobility platform designed to revolutionize how people move, book, and manage transport. From private car hires to shared transit and inter-state travel, NOMO provides a secure, transparent, and efficient ecosystem for both passengers and drivers.

---

## ✨ The "Real Deal" - Key Features

### 🚗 1. Private Car Hire (Negotiation Hub)
*   **Direct Negotiation:** Connect directly with drivers and negotiate fares based on your specific trip needs.
*   **Live Tracking:** Monitor your ride in real-time with precise GPS integration.
*   **Fleet Diversity:** Choose from a wide range of vehicles, from standard sedans to premium fleets.

### 🚌 2. Shared Load Booking
*   **Seat-Based Booking:** Book individual seats in shared vehicles (Cars, Kekes, Buses) for cost-effective commuting.
*   **Smart Scheduling:** Drivers can set meeting points and destination routes for daily transit.
*   **Cross-Check Protection:** Advanced logic prevents double-booking between shared and private services.

### 🛡️ 3. Advanced Trust System
*   **Dynamic Trust Scores:** Passenger and driver trust scores are updated based on behavior and cancellation history.
*   **Anti-Spam Controls:** Smart limits on seat switching and booking cancellations to protect driver livelihoods.
*   **Verified Profiles:** Only verified drivers with approved vehicle logs can offer services on the platform.

### 🚉 4. Transport Hub
*   **Inter-State Travel:** Management system for transport companies to list routes and manage bookings.
*   **Company Management:** Tools for transport companies to track performance and manage their fleet.

## 🛠️ Technology Stack

- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router & Turbopack)
- **Database & Auth:** [Firebase](https://firebase.google.com/) (Firestore, Auth, Cloud Storage)
- **Mapping:** [Google Maps API](https://developers.google.com/maps) (Geocoding, Places, Live Tracking)
- **Payments:** [Paystack Integration](https://paystack.com/) for secure transactions
- **Styling:** Tailwind CSS with Framer Motion for premium animations

## 🚀 Getting Started

1. **Clone & Install:**
   ```bash
   git clone <repository-url>
   cd nomo_car_hire
   pnpm install
   ```

2. **Environment Variables:**
   Create a `.env.local` file with your Firebase and Google Maps credentials.

3. **Run Development Server:**
   ```bash
   pnpm run dev
   ```
